# Final Chinese--English Terminology Glossary

| Chinese term | Final English term | Usage note |
|---|---|---|
| 无人飞行器 | unmanned aerial vehicle (UAV) | Define at first occurrence; use UAV thereafter. |
| 飞行器 | UAV | Physical object in this manuscript. |
| 飞行器集群 | UAV swarm | Use UAV swarms in the plural. |
| 进攻飞行器 | offensive UAV | Use offensive UAVs in the plural. |
| 进攻集群 | offensive UAV swarm | May be shortened to offensive swarm after definition. |
| 防御飞行器 | defensive UAV | Use only when the physical platform, rather than its role as interceptor, is emphasized. |
| 拦截飞行器 / 拦截器 | interceptor UAV / interceptor | `interceptor` is preferred after the physical context is established. |
| 主攻飞行器 | primary-attack UAV | Use primary-attack role/task for the abstract role. |
| 诱饵飞行器 | decoy UAV | `decoy containment` for the associated behavior. |
| 隐蔽飞行器 | concealment UAV | `concealment dispersion/evasion` for the associated behavior. |
| 集群协同突防 | cooperative UAV-swarm penetration | Use cooperative penetration when the UAV-swarm context is explicit. |
| 协同机动突防 | cooperative maneuvering penetration | Core mission term. |
| 攻防对抗 | offensive--defensive engagement | Avoid `game confrontation`. |
| 高价值目标 | high-value target (HVT) | Define once, then use HVT. |
| 视场 | field of view (FOV) | Define once, then use FOV. |
| 视场锥裕度 | FOV cone margin | Geometric margin relative to the detection cone. |
| 零控终端视场裕度 | zero-control terminal FOV margin | Preserve the model name. |
| 联合探测覆盖 | joint detection coverage | Use for overlapping multi-interceptor FOVs. |
| 安全裕度评估 | safety-margin evaluation | Hyphenate attributively. |
| 被捕获风险 | acquisition risk | Used for risk of entering/remaining in the interceptor detection and acquisition geometry. |
| 捕获强度 | engagement intensity | Probabilistic indicator of interceptor attention. |
| 捕获概率 | engagement likelihood | Smooth approximation of discrete interceptor intent. |
| 实际被捕获数量 | number of active interceptor assignments | Number of interceptors currently assigning the UAV as an engagement target. |
| 捕获目标 | assigned engagement target | Avoid generic `captured target`. |
| 锁定 | lock onto / engage | Select according to sensor or assignment context. |
| 探测 | detect | Sensor detection context. |
| 跟踪 | track | Continuous tracking context. |
| 目标分配 | interceptor--target assignment | Use target reassignment for subsequent switching. |
| 防御资源分配 | defensive-resource allocation | Use misallocation for resource mismatch. |
| 分配失效比 | allocation-failure ratio | Symbol remains `nu(t)`. |
| 综合拦截威胁 | aggregate interception threat | Preferred over `integrated interception threat`. |
| 任务动态重构 | dynamic task reconfiguration | Core mechanism term. |
| 任务偏好概率 | task-role probability | Use probabilities when referring to all roles. |
| 诱饵牵制 | decoy containment | Use relay containment for sequential decoy action. |
| 隐蔽分散 | concealment dispersion | Role-preservation behavior. |
| 主攻突破 | primary-attack penetration | Use primary-attack corridor/channel for the route. |
| 法向过载 | normal acceleration | Physical acceleration; do not use overload. |
| 俯仰通道过载 | pitch-plane acceleration | Used in dynamics, commands, plots, and captions. |
| 偏航 / 横向过载 | lateral acceleration | Used in dynamics, commands, plots, and captions. |
| 轴向加速度 | axial acceleration | Symbol `a_x`. |
| 过载指令 | acceleration command | Direction-qualified where needed. |
| 法向过载能力 | normal-acceleration capability | Used for interceptor tracking limits. |
| 过载约束 | acceleration constraint | Use maneuver limit when referring to a numerical bound. |
| 过载饱和 | acceleration saturation | Use acceleration-command saturation for command saturation. |
| 比例导引 | proportional navigation (PN) | Define PN if used independently. |
| 视线角速度 | line-of-sight (LOS) angular rate | Define LOS once. |
| 跟踪失配裕度 | tracking-mismatch margin | Preserve symbol `Gamma`. |
| 突防成功度 | penetration-success metric | Continuous model quantity. |
| 命中可行度 | strike-feasibility metric | Continuous model quantity. |
| 终端脱靶量 | terminal miss distance | Use SI unit `\mathrm{m}`. |
| 集中式训练分散式执行 | centralized training with decentralized execution (CTDE) | Define once. |
| 任务信任引导注意力多智能体近端策略优化 | role-trust attention multi-agent proximal policy optimization (RTA-MAPPO) | Unique full expansion used in the manuscript. |
| 信任调制探索 | trust-modulated exploration | Algorithm mechanism. |
| 注意力残差特征提取 | residual attention-based feature extraction | Algorithm mechanism. |
| 半实物 / 硬件在环仿真 | hardware-in-the-loop (HIL) simulation | Avoid `semi-physical simulation`. |
| 蒙特卡洛仿真 | Monte Carlo simulation | Capitalize Monte Carlo. |
| 消融实验 | ablation study / observation-channel ablation | Use study for the section-level concept. |
